# Receiver

Software for the receiving end — reassembles image chunks from Meshtastic mesh.

## Planned

- Python script using [meshtastic Python CLI](https://meshtastic.org/docs/software/python/cli/)
- Listens for image packets, reassembles JPEGs
- Optional Discord webhook forwarding
- Optional web dashboard for viewing photos

See [docs/SPEC.md](../docs/SPEC.md#receiver-side) for details.
